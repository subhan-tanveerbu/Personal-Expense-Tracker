# 💰 Personal Expense Tracker

A simple command-line Personal Expense Tracker built with Python. This application allows users to record, manage, search, and analyze daily expenses while storing data in a CSV file.

## 📌 Project Overview

This project was developed as a Week 1 mini project to strengthen Python fundamentals, including file handling, functions, loops, dictionaries, lists, error handling, and CSV data manipulation.

---

## ✨ Features

- ➕ Add new expenses
- 📋 View all expenses
- 🔍 Search expenses by category
- 📊 View category-wise expense summary
- 💸 Display the highest single expense
- 📄 Export summary to `summary.txt`
- 💾 Store expenses permanently in a CSV file
- ⚠️ Basic error handling for invalid inputs

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/subhan-tanveerbu/Personal-Expense-Tracker.git
```

### Navigate to the project

```bash
cd Personal-Expense-Tracker
```

### Run the application

```bash
python3 expense_tracker.py
```
